# Measurement Data

Reserved for future chip and board measurements; no measured data is present yet. Preserve original acquisitions and record device/board revision, instrument and source settings, sample rate, coding, supplies, temperature and units. Keep processed data distinguishable from raw acquisitions.

Read the [reference index](../literature/README.md) before designing a measurement procedure. Ideal simulated clocks and sources do not establish laboratory setup quality. Generated model runs are not measured data.
